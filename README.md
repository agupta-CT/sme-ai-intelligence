Owner: Maverick TG (C&T). Purpose: persistent store for the daily Applied AI intelligence agent
(role spec lives in the chat prompt; this folder is the memory).

## Files (logical artifacts required by the role spec)

| File | Purpose | Update cadence |
|------|---------|----------------|
| `AI_Intelligence_Daily_Log.md` | Execution log: run date, research window, items reviewed/selected, source limitations | Every run |
| `AI_Research_Reading_Tracker.csv` | Master tracker: one row per discovered item (see schema below) | Every run + on READ/START/SKIP/SAVE commands |
| `Applied_AI_Knowledge_Base.md` | Searchable knowledge base: paper summaries, concepts, patterns, comparisons, glossary | Every run (append), never rewrite history |
| `Applied_AI_Learning_Roadmap.md` | Competency matrix (15 competencies x 5 levels), 7-day / 30-day / 90-day plan | Monthly assessment + when plan changes |
| `Weekly_AI_Research_Review.md` | Weekly review (Sunday per spec section 8; the summary table says Saturday - spec conflict, default Sunday) | Weekly |
| `daily_reports/YYYY-MM-DD.md` | Full daily brief as sent/intended for email | Every run |
| `knowledge/` | Long-form deep dives generated by DEEP DIVE / EXPLAIN / COMPARE / IMPLEMENT commands | On demand |

## Tracker schema (`AI_Research_Reading_Tracker.csv`)

`item_id,title,category,org_authors,url,published_date,discovered_date,priority,score,status,est_read_min,key_takeaway,topics,follow_up,last_reviewed,history`

- `item_id`: stable, sequential, zero-padded: `AI-0001`, `AI-0002`, ... Never reuse or renumber.
- `category`: research | product | framework | company | platform | security | foundational | resource
- `priority`: P1 | P2 | P3 | Watchlist
- `score`: 0-100 (weights: tech significance 25, applied-AI impact 25, novelty 20, industry relevance 15, strategic 15)
- `status`: Not Started | In Progress | Read | Skipped | Archived. ONLY the owner moves an item to Read.
- `history`: semicolon-separated `YYYY-MM-DD: note` entries for updates to an existing item (no duplicate rows).
- Duplicate check before insert: match on URL, arXiv ID, DOI, or normalized title.

## Owner commands (type in chat)

`READ <id>` | `START <id>` | `SKIP <id>` | `SAVE <id>` (add to priority queue) | `DEEP DIVE <id>` | `EXPLAIN <id>` | `COMPARE <id>` | `IMPLEMENT <id>` | `REVIEW` | `WEEKLY REVIEW`

## Daily execution checklist (spec section 12)

1. Read `AI_Intelligence_Daily_Log.md` (last successful scan) + tracker + knowledge base.
2. Scan window = last successful scan -> now. Primary sources first.
3. Score, prioritize, de-duplicate (check tracker by URL / arXiv ID / title).
4. Write `daily_reports/<date>.md` in the section 6 format; append to daily log; append new tracker rows; append KB entries.
5. Refresh reading queue; record limitations honestly. Never fabricate; never mark Read automatically.
6. Deliver: email "Daily - AI Digest (SME Edition) - <Date>" (requires Gmail connector) - if delivery is unavailable, say so in the log.

## Schedule (target)

- Daily scan: 07:00 America/New_York (= 12:00 UTC in EST, 11:00 UTC in EDT)
- Weekly review: Sunday
- Monthly competency assessment: last day of month
